# EDUON P3 수강·결제 내부 검증

검증일: 2026-11-09 (Asia/Seoul). 작업 브랜치: `codex/eduon-p3`.

상태: **공급자 선택을 보류한 내부 구현·테스트 범위 완료. 실제 PG sandbox·실결제·운영 환불·자동 송금은 미연결.** P3 DB 변경은 격리된 로컬 테스트 DB에만 적용했다.

브라우저 테스트는 자녀 선택부터 결제·수강권까지, 위조 결과 URL과 타 계정 접근 거부, 응답 유실 후 같은 요청키로 재시도해 주문 하나만 생성, 부분 환불의 상태 변경, 운영자 작업 재처리를 확인했다. 테스트 세션은 실제 Supabase 로그인의 대체 증거가 아니다.

checkout·결과·주문·학원 재무·운영자 거래의 **360/390/768/1024/1440px** 화면 25개를 캡처했다. 390/1440px의 10개 axe WCAG A/AA 자동 검사에서 위반이 없었다. 수동 보조기술·실제 기기·Safari까지 검증했다는 의미는 아니다. 주요 캡처 10개는 `docs/operations/screenshots/p3-*.png`에 보관했다.

## 검토에서 재현하고 수정한 문제

1. 수강권 발급이 불가능한 결제를 확인할 때 결제 증거까지 롤백하던 문제를 결제 사실·예외·보상 환불의 원자적 저장으로 수정했다.
2. 환불을 처리 중으로 바꾼 직후 중단하면 첫 외부 요청도 재개하지 못하던 문제를 같은 요청키로 복구하게 했다.
3. 오래된 환불 작업 응답이 새 환불의 회차 보류를 해제하던 경합을 환불 시도 세대로 차단했다.
4. 이미 지급된 주문의 환불액이 다음 정산에서 빠지지 않던 문제를 짝 조정 원장과 학원 전체 잔액 한도로 수정했다.
5. 실패한 첫 100개 작업 뒤의 거래가 재조회되지 않던 문제를 검색 커서의 영속 저장으로 수정했다.
6. 오래된 부분 환불 응답이 전체 환불 상태를 되돌리던 문제를 최종 상태·성공 환불 합계로 방지했다.
7. 동일 서명 웹훅의 동시 재전송에서 하나가 고유 제약 오류로 실패하던 문제를 이벤트별 트랜잭션 잠금으로 수정했다.

앞의 여섯 항목은 별도 읽기 전용 검토자가 재검토했으며 미해결 코드 지적이 없었다. 실제 공급자와 계약을 붙이기 전에는 이 검증을 운영 결제 승인으로 사용하지 않는다.

## 스킬과 한계

승인된 superpowers 계획을 따라 실패 테스트·구현·검증과 작업별 검토를 수행했다. gstack review의 금액·SQL·권한·외부 증거 신뢰 경계 기준을 적용하고 브라우저 검증은 Playwright로 실행했다. 정식 gstack browse 데몬 실행 성공이나 실제 공급자 sandbox 통과를 주장하지 않는다.

가짜 PG의 공급자 기록은 메모리이므로 프로세스 재시작 후 외부 결제 조회의 영속성을 증명할 수 없다. 장애 작업·주문·환불·원장은 DB에 영속 저장한다. 스케줄러 엔드포인트는 HMAC·만료·nonce 재전송 차단을 구현했지만 실제 주기 실행 배포와 외부 경보 채널은 구성하지 않았다.

현재 학습 화면의 입장·출결·과제는 P4 범위다. P3에서는 학생 수강권과 회차 권리를 DB에서 확인했으며 새 학생 수업 입장 기능은 구현하지 않았다. 일반 가입 정책, 실제 수수료·환불·판매자 책임, PG 계약과 운영 정산은 [결정 기록](commerce-decisions.md)을 따른다. 검증 로그의 pg 8 중첩 쿼리 deprecation 경고는 남아 있으나 테스트 실패는 없고 pg 9 업그레이드는 이번 범위에 포함하지 않았다.

CI에 P3와 마이그레이션 테스트를 추가했으며, 이번 작업에서 원격 CI·배포는 실행하지 않았다.
