# 수업 분야·일반인 대상 확장

2026-11-09. 기존 수학·영어를 보존하고 다음 네 분야를 추가했다.

| 코드           | 표시          |
| -------------- | ------------- |
| programming    | 프로그래밍    |
| ai_usage       | AI 활용       |
| ai_certificate | AI 자격증     |
| ai_agent       | AI Agent 개발 |

검색 필터·홈 분야 링크·카드·상세·원장 수업 개설·학습자 분류·추천 검증이 같은 `src/contracts/catalog.ts` 값을 사용한다. 기존 학년 1~12는 그대로 유지하며 13은 일반인 분류다. 최소/최대가 모두 13이면 ‘일반인’ 한 번만 표시한다. 일반인 분류는 나이나 보호자 권한의 증거가 아니며 기존 로그인·연결·결제 권한 검사는 유지한다.

데모에 가상 디지털 학원과 일반인 과정 4개, 각 과정의 예시 학습 주제 4개를 추가했다. 실제 학원의 수업·교육과정으로 시드하지 않았다. 특정 자격시험 명칭·공식 인증·합격을 보장하지 않는다. 실제 데이터 모드에서는 등록된 수업만 노출하며 새로운 과목을 선택해도 기존에 등록한 과정이 없으면 빈 결과가 정상이다.

## DB 적용

`0004_catalog_expansion`은 Course의 과목·대상 CHECK와 StudentProfile 대상 CHECK를 확장한다. 열·기존 레코드·학년 코드를 변경하거나 삭제하지 않는다. 과목 unknown과 대상 14 등은 DB와 서버에서 계속 거부한다. 원격 DB에는 이번 마이그레이션을 적용하지 않았다.

실제 DB에서 새 과목/일반인 수업을 저장하려면 대상 환경의 백업·적용 이력을 확인한 후 마이그레이션을 적용해야 한다. 현재 원격에는 앞선 P3/P4 미적용 migration도 있을 수 있으므로 `db:migrate`가 0004만 실행한다고 가정하지 않는다. 이번 구현에서 실수강이나 운영 정책을 활성화하지 않았다.

## 검증

- 새 과목/일반인 검색·추천·표시 단위 테스트 5개를 먼저 실패 확인했다. 전체 단위 90개 통과.
- 새 과목별 일반인 수업 개설→공개→DB 검색 4개, 일반인 학습자 저장·잘못된 DB 값 거부 1개를 먼저 실패 확인하고 수정 후 5개 통과.
- 기존 검색·수업 승인/개설·같은 과정 기수 회귀 포함 통합 32개 통과.
- 0001~0004의 새 격리 DB 마이그레이션 적용 통과.
- 원장 UI로 기존 영어·일반인 AI Agent 과정 개설/공개/필터 검색, P2 전체 브라우저 9개 통과.
- 공개 화면의 390/1440px 네 분야 검색·상세·일반인 표시·가로 넘침·axe 대상 테스트 2개 통과. 전체 공개 회귀에서는 25개가 통과했고 접근성 1개가 실패해 원인을 수정한 뒤 대상 2개를 모두 재검증했다. 초기 전체 axe 검사에서 공통 로고의 보이는 이름과 접근성 이름 불일치를 발견해 수정했다.
- 타입 검사·린트·최종 빌드 통과.

기존 P2 브라우저 테스트의 Next dev 요청 취소 ECONNRESET·pg deprecation 경고가 일부 출력됐으나 테스트 9개는 통과했다. 실제 제공자·원격 데이터·신규 일반인 본인 결제의 전체 운영 검증을 의미하지 않는다.
